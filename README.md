# Tiny Farm (Love2D)

A cozy, 2D farming simulation prototype built with the [LÖVE (Love2D)](https://love2d.org/) framework. 

## Features
- **Farming Loop**: Clear land, till soil, plant seeds, water crops, and harvest.
- **Tools**: Hands, Axe, Pickaxe, Hoe, Watering Can, and Seeds.
- **Day/Night Cycle**: Manage your energy and sleep to progress time and grow crops.
- **Economy**: Ship crops in the shipping bin and earn gold overnight.

## Requirements
- [LÖVE 11.4+](https://love2d.org/)

## Running the Game
To run the game, simply pass the project directory to the `love` executable from your terminal:
```bash
love .
```
